# Проект PythonPHome2

## Описание:

Проект это веб-приложение на Python. Курсовая № 1. Работа с ВЭБ-страницами

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:Skripnik072/Kurswork1.git
```

## Использование:

1. Приложение позволяет считывать тразакции из файлф Excel.
2. Позволяет получать данные из API о курсах валют, перечисленных в файлу user_settings.json.
3. Позволяет получать данные о котировках акций, перечисленных в файлу user_settings.json.
4. Выдает информацию о топ-5 транзакций по сумме, валютах и акциях в формате JSON-ответа.
5. Обеспечивает поиск транзакций по ключевому слову в описании или категории.
6. Позволяет рассчитать расходы по выбранной категории.
